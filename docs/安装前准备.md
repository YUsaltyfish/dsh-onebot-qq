# 安装说明（还要装什么）

> 目标：**装完即用**。下面只列「插件包内解决不了」的东西，其余插件自己搞定。

## 一、需要外部准备的（只有 2 项）

1. **DSH ≥ 0.2.1-rc.2**（`dsh --version`）
   低版本没有 `sessionController` / 原生工具注册，插件无法代升级 → 先升级 DSH。
2. **NapCat 已登录一个 QQ 小号**，并开启 OneBot v11：
   正向 WebSocket `127.0.0.1:3001` + HTTP `127.0.0.1:3000`（有 token 就填进控制台）。
   NapCat 是外部 QQ 协议端，插件不能替你装/登录。

## 一·补（可选）：QQ 线工具门

如果 profile 里还有**全局工具插件**（`dsh-ops` 的 `ops_*`、agent-team、MCP 资源等），它们会绕开 qq-chat preset 的裁剪，漏进 QQ 会话（更费 token，也多出主机能力）。

想让 QQ 线只保留「聊天 / 联网 / 生图 / 表情 / 群记忆」那一套，再装配套的独立插件 **`dsh-onebot-qq-opsgate`**（安装与原理见 [安装与卸载.md](安装与卸载.md)「可选：QQ 线工具门」）：

- 它只覆盖 `qq-chat` preset 这一行，在列表末尾追加自己，然后在 agent scope 里 `ctx.tools.restrict({ deny })` 挡掉全局工具；
- **只影响 QQ 会话**，不碰网页 / 工作线 / 其他 preset；
- 不装也完全不影响聊天，只是工具面更大。

## 二、插件自己会做的（装完不用管）

- 声明并自动启用内置 `qq-chat` preset（纯聊天 + 联网；bash/pwsh/文件/任务/技能/插件管理类工具全裁）
- 自动创建「QQ 聊天」工作区，QQ 会话集中归组
- 首次启动**自动投递内置默认人设「蓝色大肥鱼」**（人设库 + QQ 线投递，开箱就有口吻；已有投递/已配人设就跳过）
- 缺 QQ 号时进入「待配置模式」+ 新手向导；`config.json` 自动生成；一键诊断
- 启动自检：控制台「运维 → 🧪 检查运行环境」
- 「NapCat 连接」页 = 连接状态 + 连接配置 + 「🔌 测试连接」，与「总览」**同一状态源**（5 秒轮询：NapCat 掉线/QQ 上下线会自动刷新）。
  **扫码/密码登录请用 NapCat 自带 WebUI**（默认 `http://127.0.0.1:6099`），插件不代做登录。

## 三、极端情况（只有自定义极简 profile 会遇到）

宿主若**完全没有** `workspaceRegistry` / `agentPresets` 服务：插件自动降级（不归组 / 用默认工具面），
并提示补装。由 DSH 执行（装完重启）：

```bash
dsh plugin --profile <profile> add @deepseek-ai/dsh-workspace
dsh plugin --profile <profile> add @deepseek-ai/dsh-agent-preset-registry
```

## 四、验收（3 条）

- 控制台「🧪 检查运行环境」**必需项全绿**（`sessionController` / `tools` / `dataDirWritable`）
- 侧栏有「QQ 聊天」工作区；配置里 `agentPreset = qq-chat`
- 私聊发一句 → 有回复；会话在该工作区里，工具面没有 shell/文件类

> 装好后把 [`manual.md`](使用说明书.md)（使用说明书）给使用者看：安装 → 连接 → 各功能怎么用 → 人设怎么写。

## 五、人设怎么写（可选）

安装后插件会**自动投递内置默认人设「蓝色大肥鱼」**（`init` 也会；已有投递/已配人设就跳过，不覆盖你的文件），
开箱就有口吻，**不需要手动创建**。

**人设模板随包**：`examples/personas/_模板.md`（首次启动会一并复制进 `<dataDir>/personas/_模板.md`）。
要做新人设，**让 AI 照着这份模板写**（模板里有：五条声音指纹、必备纪律、装饰配额、示范对话写法、句池/唤醒词规范、保存前自检清单），
写完放进人设库 `<dataDir>/personas`：

| 文件 | 写什么 |
|---|---|
| `<名字>.md` | 人设正文：它是谁、怎么说话、有什么忌讳（投递成 QQ 线的 `AGENTS.local.md`）|
| `<名字>.lines.txt` | 句池：`## poke` 被戳、`## callAck` 答应、`## imageAck` 在画了…（可省略；缺的节继承底池 `_default.lines.txt`）|
| `<名字>.wake.txt` | 群里叫它不用 @ 的唤醒词（每行一个/逗号分隔；可省略 = 用控制台的唤醒词）|

默认人设自带唤醒词「大肥鱼」（群里不 @ 也能叫它）；控制台「群聊」页加的免@唤醒词会与它**合并生效**，不用二选一。

写完在控制台「总览 → 人设」点一下这个名字即切换（下一条消息生效）；命令行也可以：
`node bin/dsh-onebot-qq.mjs persona use <名字>`。默认那套可以直接参考 `<dataDir>/personas/蓝色大肥鱼.*`。

## 六、回滚

preset 异常 → 在实例 `config.json` 把 `dsh.agentPreset` 留空（或改回 `qq-chat`）；插件回滚 → `dsh plugin --profile <profile> remove dsh-onebot-qq`（数据目录保留）。
